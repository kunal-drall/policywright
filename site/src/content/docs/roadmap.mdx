Built in response to the SCF 'OZ accounts policy builder' RFP (Q2 2026), funded
in round [SCF #44](https://communityfund.stellar.org/awards/rec4FnYypcsKpBRB4)
as the awarded submission
['Record-to-Policy MCP + Agent skill.'](https://communityfund.stellar.org/project/policywright-j8x)
The plan has three tranches — **MVP → Testnet expansion → Mainnet launch**.
The only dates on this page are the communicated tranche targets. Every
shipped row links to the section of
[evidence/EVIDENCE.md](https://github.com/kunal-drall/policywright/blob/main/evidence/EVIDENCE.md)
that quotes its approved criterion verbatim and gives the verification
commands, and to a green CI run.

The close-out work of 2026-09-02 — the demo script from real runs, the second
install (rule ids 4–6), the re-install-safe `verify`, the tranche form draft —
is in
[evidence § Tranche 2 close-out](https://github.com/kunal-drall/policywright/blob/main/evidence/EVIDENCE.md#tranche-2-close-out--truthfulness-pass-demo-script-form)
([CI run 33654005983](https://github.com/kunal-drall/policywright/actions/runs/33654005983)).

**Not built in Tranche 2, stated plainly:** the wallet signing page (it
replaces only the installer's signing surface — the `Delegated(G)` model is
proven with the local key as `G`), an on-chain argument-scoping policy (the
harness enforces argument scope offline; not an approved T2 criterion), and
the optional post-install enforcement demo. Each is tracked in
[docs/T2-NOTES.md](https://github.com/kunal-drall/policywright/blob/main/docs/T2-NOTES.md).

## Tranche 3 — planned, target 30 Nov 2026

Nothing under this heading exists in the repository. Ideas that surface early
are parked in
[docs/T3-NOTES.md](https://github.com/kunal-drall/policywright/blob/main/docs/T3-NOTES.md).

| Item                                                                                                                | Status  | Target      |
| ------------------------------------------------------------------------------------------------------------------- | ------- | ----------- |
| Three documented end-to-end walkthroughs                                                                            | Planned | 30 Nov 2026 |
| OpenZeppelin validation of the generated code and the compose-first install mapping                                 | Planned | 30 Nov 2026 |
| Production release — versioned MCP server, packaged skill, docs                                                     | Planned | 30 Nov 2026 |
| Mainnet demonstration                                                                                               | Planned | 30 Nov 2026 |
| Audit readiness — audit of the synthesizer logic and the generated policy templates via the **SCF Audit Bank**      | Planned | 30 Nov 2026 |

Until that audit has happened, every generated contract stays stamped
illustrative and unaudited, and deployment stays testnet-only
([Security](/security/)).
